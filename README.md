
## ⚙️ Funcionalidades
1. **Render dinámico de imágenes**: las fotos se generan desde `main.js` usando un arreglo de objetos.
2. **Favoritos**: al hacer clic en una imagen, se agrega automáticamente a la sección de favoritos.
3. **Buscador dinámico**: filtra las imágenes en tiempo real mientras se escribe en el input.
4. **Formulario de contacto**: valida que los campos estén completos y muestra un mensaje de confirmación.
5. **Estilos CSS**: galería ordenada en fila, con efectos de hover y favoritos destacados.

## 📜 Requerimientos cumplidos
- Uso de `const` y `let`.
- Uso de **arreglos** y **objetos**.
- Implementación de **funciones propias** y al menos una **arrow function**.
- Manipulación del **DOM** con `querySelector`, `createElement`, `appendChild`, `innerHTML`.
- Uso de **eventos** con `addEventListener`.
- Integración con el proyecto anterior (HTML + CSS).
